# 多空辩论工作流

让多个 AI 角色围绕同一份客观事实底稿互相质疑。产物是「多方怎么说、空方怎么说、双方在哪儿真正分歧、要证伪各自需要什么证据」，结论留给用户自己下。

## 共同准则（必须严格遵守）

- 只能使用底稿里的数据立论。底稿没有的数字一律不许编造，需要但缺失的，明确写「该数据缺失」。
- 每条论点都要标出所依据的具体数据（写清数值），没有数据支撑的直觉判断要标注「无数据支撑」。
- 不推荐买卖、不预测股价涨跌与具体价位、不给买卖时机、不给目标价、不给评级或排名、不承诺收益。
- 用简洁中文，条目化输出。
